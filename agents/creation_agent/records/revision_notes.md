# Assignment 2 - Revision Notes

## Preserved weak output

It generalized the RAG origin papers into the claims that RAG "improves factual accuracy and reduces hallucination" and that a financial-services firm "should adopt RAG." ## Revision
The v1.1 specialist instructions added:
- a creation-to-use alignment check;
- explicit evidence-versus-inference discipline;
- a rule that general creation history must remain stable across context contrasts;
- a prohibition on turning historical motivation or research benchmarks into universal current-performance guarantees; and
- explicit handoff boundaries for significance, diffusion, readiness, adoption, ROI, governance, regulation, security, and production deployment.

## Result
The primary and contrast responses now preserve the same general RAG history while producing different application and organization implications. The validator confirms schema compliance; professional adequacy still depends on human review of the evidence and judgment.
